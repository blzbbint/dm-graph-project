# 출력 형식 (반드시 이대로)

정점 구분자: ` - ` (빈칸-하이픈-빈칸)
구분선: 하이픈 30개 / 등호 30개 (아래 템플릿 그대로 복사)

## 전체 구조
```
1. 그래프 탐방 수행 결과

그래프 [1]
------------------------------
깊이 우선 탐색
1 - 2 - 4 - 8 - 5 - 6 - 3 - 7
너비 우선 탐색
1 - 2 - 3 - 4 - 5 - 6 - 7 - 8
==============================

2. 최단 경로 구하기 수행 결과

그래프 [1]
------------------------------
시작점: 1
정점 [2]: 1 - 5 - 4 - 2, 길이: 5
정점 [3]: 1 - 3, 길이: 4
정점 [4]: 1 - 5 - 4, 길이: 2
정점 [5]: 1 - 5, 길이: 1
==============================
```

## 규칙
- input1의 각 그래프마다: 그래프 [i] → DFS → BFS, 그래프 끝에 등호선.
- 탐방(1번) 전부 끝난 뒤 최단경로(2번) 출력.
- input2의 각 그래프마다: 시작점 1, 정점 2..n 순서로 "정점 [k]: 경로, 길이: d".
- 경로 길이가 같으면 먼저 찾은 경로 출력 → 갱신은 < 일 때만 (<= 금지).
- 그래프 번호 [i]는 1부터.

## printf 참고 (각자 구현에서 사용)
깊이/너비 방문 순서 (배열 order[], 개수 cnt):
    printf("%d", order[0]);
    for (int i = 1; i < cnt; i++) printf(" - %d", order[i]);
    printf("\n");

최단경로 한 줄 (경로 path[], 개수 len, 거리 dist):
    printf("정점 [%d]: ", v);
    printf("%d", path[0]);
    for (int i = 1; i < len; i++) printf(" - %d", path[i]);
    printf(", 길이: %d\n", dist);

구분선:
    // 그래프 머리 아래
    printf("------------------------------\n");
